# Telecom Customer Churn Prediction

## Overview
This project predicts customer churn using machine learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit

## Features
- Data preprocessing
- Model training
- Customer churn prediction
- Streamlit deployment

## Outcome
Built a predictive model to identify customers likely to leave the telecom service.
